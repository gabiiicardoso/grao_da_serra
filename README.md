Conexão com o Banco de Dados

Para conectar a interface do sistema Empório & Café Grão da Serra ao banco de dados MySQL (grao_da_serra), o front-end foi desenvolvido em HTML, CSS e JavaScript e o back-end em Node.js com Express. Como o navegador não se comunica diretamente com o MySQL, o servidor Node.js atua como programa intermediário utilizando o pacote mysql2 para gerir a ligação. Os dados sensíveis de acesso ao banco (host, utilizador, palavra-passe e nome da base) ficam isolados no arquivo .env dentro da pasta servidor, que não é enviado para o GitHub. Na prática, sempre que a interface precisa de consultar ou alterar dados, as funções do módulo api.js realizam requisições fetch para as rotas do servidor Express, que por sua vez executam comandos SELECT nas views (como vw_cardapio e vw_pedidos_detalhados) ou CALL nas procedures (como sp_abrir_pedido e sp_finalizar_pedido), devolvendo os resultados ou eventuais mensagens de validação (SIGNAL) para serem exibidos na tela.
